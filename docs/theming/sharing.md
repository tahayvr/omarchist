# Sharing Themes

Exporting and importing themes from the app is not available yet.

To share a theme today, copy its folder from `~/.config/omarchy/themes/`. A copied folder works on any Omarchy Quattro machine.

If you share a theme as a git repository, people install it with `omarchy theme install`. Omarchy then skips the parts of a theme that could run code: a customized Neovim, Terminal Menus, Terminal Colors, and VS Code Extension. See [Optional Tabs](/theming/optional-tabs#sharing-a-theme-through-git).
